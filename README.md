# CMP Redesign

## Project Overview

The **Corporate Mentorship Program (CMP) Redesign** is a project management and business process improvement initiative focused on redesigning the existing CMP experience to make the program more structured, transparent, and effective for both mentors and mentees.

The project was undertaken to identify key process-level challenges within the CMP and develop practical solutions that improve coordination, communication, feedback, tracking, and the overall participant experience.

The redesign focused on three major problem areas:

1. **Mentor–Mentee Mapping**
2. **Feedback Management**
3. **Grand Finale Planning**

---

## Problem Statement

The existing CMP process involved multiple stakeholders, activities, and coordination points. This created challenges in maintaining an efficient and consistent experience throughout the program.

Three major pain points were identified:

### 1. Mentor–Mentee Mapping

The mentor–mentee allocation process required a more structured approach to ensure appropriate mapping, better visibility, and smoother coordination between mentors and mentees.

### 2. Feedback Management

The existing feedback mechanism created challenges in capturing, tracking, and monitoring mentor–mentee interactions and feedback.

A more structured feedback mechanism was required to improve visibility and enable timely follow-up.

### 3. Grand Finale Planning

The Grand Finale involved multiple activities and stakeholders, creating a need for better planning, coordination, tracking, and execution.

---

## Project Objective

The objective of the CMP Redesign project was to redesign the key processes of the Corporate Mentorship Program and develop a more structured operating model.

The project aimed to:

- Improve mentor–mentee mapping
- Create a more structured feedback mechanism
- Improve visibility of mentor–mentee engagement
- Reduce manual coordination and follow-ups
- Improve process tracking and monitoring
- Strengthen coordination among stakeholders
- Improve planning and execution of the Grand Finale
- Create a more transparent and manageable CMP workflow
